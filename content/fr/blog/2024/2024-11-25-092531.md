## 2023-08-14: Les dernières nouvelles de la communauté

### Nouveautés dans le développement
- Support pour les extensions de fichiers `.webp` dans les images statiques
- Amélioration de la performance du serveur grâce à l'optimisation des requêtes API
- Ajout d'une fonctionnalité de prévisualisation pour les fichiers Markdown

### Mise à jour du site web
Le site web a été entièrement révisé pour améliorer l'expérience utilisateur. Les modifications incluent :
- Interface utilisateur moderne et responsive
- Meilleure navigation grâce à un menu en barre latérale
- Optimisation du chargement des pages grâce à la mise en cache

### Problèmes connus
- Certains navigateurs peuvent afficher incorrectement les images `.webp`
- Le serveur peut parfois tarder à répondre sous une forte charge

Vous pouvez contribuer à ce projet en :

- [Participer aux discussions sur le forum](https://forum.mon-projet.org)

> 💡 **Astuce** : Pour tester les nouvelles fonctionnalités, utilisez l'environnement de développement local.
