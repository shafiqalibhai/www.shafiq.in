Final Year Project Abstract — Test Automation in ERP Applications

6 August 2009 · Shafiq Alibhai

This was my final year project for the B.Tech in Computer Science and Engineering (2008–09), done with K. Nishant.

Test Automation in ERP Applications: Optimisation and Enhancement

Most large organisations run their business on packaged ERP systems like SAP, Oracle, or PeopleSoft. These get heavily customised to fit each company’s processes, and testing those customisations is expensive and time-consuming. The goal of this project was to build a test automation framework that could run hundreds of test scenarios from a single script.

The problem

Test automation tools existed, but the frameworks around them needed work. We wanted to make the process faster and more reliable, especially for ERP implementations where testing cycles are long and budgets are tight.

Tools and technologies

  • QuickTest Professional (test execution engine)
  • VBScript
  • Microsoft Windows XP
  • SAP, Oracle, PeopleSoft
