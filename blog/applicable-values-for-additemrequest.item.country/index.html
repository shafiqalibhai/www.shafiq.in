26 October 2013 · Shafiq Alibhai

Applicable values for AddItemRequest.Item.Country#

When listing an item via the eBay Trading API, the Item.Country field expects a two-letter ISO 3166-1 alpha-2 country code. The table below lists every value eBay accepts, along with the country name.

All codes are valid for both incoming (selling) and outgoing (shipping) directions unless noted otherwise.
