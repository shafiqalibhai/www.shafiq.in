Posters for Udbhav 2009

A set of posters for Udbhav 2009. The goal was to build a visual identity that felt fresh and energetic, something that would stand out on notice boards and social media alike. Each poster uses a different colour way but shares the same typography and layout so they read as a family.

This was part of a larger design effort for Udbhav 2009 that also included flyers, stickers, mini banners, the souvenir book cover, the participation certificate, and the stage backdrop.
