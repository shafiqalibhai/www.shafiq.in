GNUSL3S Linux

GNUSL3S Linux is a distribution built in Goa. It bundles a wide range of pre-installed software spanning bioinformatics (EMBOSS, Primer3), security tools for penetration testing, system administration utilities, and development editors. Boot from the DVD for a graphical interface with KDE, XFce, Fluxbox, or IceWM.

  • Based on: Slackware, SLAX, Alixe, Davix
  • Version: 10.05.xx
  • Architecture: i486 (32-bit)
  • Origin: Goa, India
  • Status: Discontinued
