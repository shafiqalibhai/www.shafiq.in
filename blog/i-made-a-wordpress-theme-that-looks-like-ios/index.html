I made a WordPress theme that looks like iOS

31 October 2012 · Shafiq Alibhai

I’ve been staring at my iPhone all day and I got tired of how every WordPress blog looks the same – flat headers, generic sidebars, the whole deal. So I spent the evening building a theme that actually looks like iOS, and I’m putting it up for anyone who wants it.

The whole thing is built around that familiar iOS table view look. Striped background, rounded white cells with the little chevron arrows, a search bar at the top that matches the system aesthetic. It’s not trying to be a 1:1 copy of the iPhone – it’s just borrowing enough of the visual language that people who spend their days in iOS will feel at home.

I kept it simple on purpose. No fancy animations, no JavaScript frameworks, no bloat. Just CSS that does what it needs to do and a template structure that WordPress already understands. You install it, you write a post, and suddenly your blog looks like it belongs inside Settings.

The theme is available on my site if you want to grab it. There’s a live demo too, though I’d recommend checking it on a phone if you can, because that’s really where the joke lands.
